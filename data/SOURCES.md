# Источники учебного видео

Видео `data/sample.mp4` — 10–60 секунд, с зебрами в кадре. Файл в репозиторий не коммитится, если он большой (держать до нескольких МБ).

| Поле | Значение |
|---|---|
| Файл | `data/sample.mp4` |
| Источник (ссылка) | _заполнить_ |
| Автор | _заполнить_ |
| Лицензия | _заполнить (например, CC0 / CC BY / Pexels License)_ |
| Что изменено | _например: обрезка до N секунд, уменьшение разрешения_ |
